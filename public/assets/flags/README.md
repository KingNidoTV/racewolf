# Drapeaux pilotes

Fichiers SVG locaux (ISO 3166-1 alpha-2 + `gb-eng` / `gb-sct` / `gb-nir` / `gb-wls` / `un`).

Régénérer :

```bash
node scripts/download-flags.js
```

Source : [flagcdn.com](https://flagcdn.com). Le classement utilise d’abord ces fichiers pour fonctionner hors ligne dans le portable.
