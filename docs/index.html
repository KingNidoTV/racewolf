Windows 10 / 11

Télécharger RaceWolf

Fichier portable : double-clic, pas d’install. iRacing est nécessaire pour l’overlay live. Le mode démo et Pit Crew fonctionnent sans le sim.

Télécharger RaceWolf 0.5.0

v0.5.0 · portable · Windows

  1. Télécharge le .exe portable, puis lance-le.
  2. SmartScreen peut bloquer l’app (elle n’est pas signée) : Informations complémentaires → Exécuter quand même.
  3. Dans le launcher, clique Lancer l’overlay avec iRacing ouvert, ou ouvre Pit Crew.

RaceWolf n’est pas affilié à iRacing.com Motorsport Simulations.

Version 0.5.0 · Windows 64 bits
